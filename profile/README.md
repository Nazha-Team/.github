## 🎵 Commands

<div align="center">

### 📝 **Complete Command Reference**

</div>

<details>
<summary><b>🎶 Music Playback Commands</b></summary>

```
/play <song>      - Play a song from any platform
/pause            - Pause the current track
/resume           - Resume playback
/skip             - Skip to the next track
/previous         - Go back to the previous track
/stop             - Stop playback and clear queue
/nowplaying       - Show currently playing track
/queue            - Display the current song queue
/volume <0-200>   - Adjust playback volume level
/seek <time>      - Jump to a specific timestamp
/shuffle          - Randomly shuffle the queue
/loop             - Toggle loop mode (off/track/queue)
/remove <number>  - Remove a specific track from queue
/move <from> <to> - Rearrange queue positions
/clear            - Clear the entire queue
/jump <number>    - Jump to a specific queue position
```
</details>

<details>
<summary><b>🎚️ Audio Filters & Effects</b></summary>

```
/bassboost <level>  - Apply bass boost (none/low/medium/high/extreme)
/nightcore          - Enable nightcore speed-up effect
/vaporwave          - Apply vaporwave slow-down effect
/8d                 - Enable 8D audio surround effect
/karaoke            - Apply karaoke vocal reduction
/tremolo            - Add tremolo modulation effect
/vibrato            - Add vibrato modulation effect
/speed <0.5-2.0>    - Change playback speed multiplier
/pitch <0.5-2.0>    - Adjust audio pitch multiplier
/reset              - Reset all active audio filters
/filters            - View all available filter options
```
</details>

<details>
<summary><b>📋 Playlist Management</b></summary>

```
/playlist create <name>       - Create a new empty playlist
/playlist add <name>          - Add current track to playlist
/playlist remove <name> <#>   - Remove a track from playlist
/playlist load <name>         - Load and play a playlist
/playlist list                - View all your saved playlists
/playlist delete <name>       - Delete a playlist permanently
/playlist info <name>         - Show detailed playlist info
/playlist share <name>        - Share playlist with others
/favorites add                - Add current track to favorites
/favorites list               - View your favorited tracks
/favorites play               - Play all your favorites
```
</details>

<details>
<summary><b>⚙️ Settings & Configuration</b></summary>

```
/247              - Toggle 24/7 continuous playback mode
/autoplay         - Enable/disable automatic song recommendations
/lyrics           - Display synchronized song lyrics
/history          - View your recent playback history
/search <query>   - Search for tracks across all platforms
/dj setup         - Configure DJ role permissions
/announce         - Toggle track announcement messages
/language <lang>  - Change bot interface language
/prefix <prefix>  - Change legacy text command prefix
/setup            - Run quick server configuration wizard
```
</details>

<details>
<summary><b>ℹ️ Information & Help</b></summary>

```
/help             - Show interactive help menu
/commands         - List all available commands
/stats            - View bot performance statistics
/ping             - Check current bot latency
/invite           - Get bot invite link
/support          - Join the support server
/about            - Learn more about Nazha
/vote             - Support us (optional, no rewards)
```
</details>

## ❓ Frequently Asked Questions

<details>
<summary><b>Is Nazha really 100% free? No hidden costs?</b></summary>

**Yes!** Nazha is completely free with zero paywalls, no premium tiers, no vote requirements, and no hidden costs. All 70+ features are available to everyone, always. We believe music should be free for everyone.

</details>

<details>
<summary><b>Do I need to vote to unlock features?</b></summary>

**Absolutely not!** Unlike other bots, Nazha has ZERO vote locks. You never need to vote to access any feature. Voting is entirely optional and purely for support — no rewards or unlocks attached.

</details>

<details>
<summary><b>What music platforms does Nazha support?</b></summary>

Nazha supports **YouTube**, **YouTube Music**, **Spotify** (tracks & playlists), **SoundCloud**, **Apple Music**, **Deezer**, **Bandcamp**, **Twitch streams**, and direct **MP3/URL** playback. We're constantly adding more!

</details>

<details>
<summary><b>Can Nazha play music 24/7 in my server?</b></summary>

**Yes!** Nazha includes a free 24/7 mode for continuous music playback. Simply use `/247` to enable it. No premium subscription needed — it's free for everyone.

</details>

<details>
<summary><b>How do I set up Nazha in my server?</b></summary>

It's easy! (1) Invite Nazha with the link above. (2) Join a voice channel. (3) Type `/play` and search for a song. That's it! Use `/help` to explore all features or `/setup` for advanced configuration.

</details>

<details>
<summary><b>What permissions does Nazha need and why?</b></summary>

Nazha requires: **Connect** (join voice), **Speak** (play audio), **Send Messages** (command responses), **Embed Links** (rich displays), **Use Slash Commands** (interaction), and **Use Voice Activity** (voice state). Just these 6 permissions — nothing more.

</details>

<details>
<summary><b>How can I get support if something isn't working?</b></summary>

Join our **Discord support server** using the link above! Our team and community are active 24/7 and ready to help with any issues, questions, or feedback you may have.

</details>
